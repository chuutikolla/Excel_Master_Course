# Excel Master Course — GitHub Upload Package

All files are placed directly in the repository root; there are no nested folders.

## GitHub upload
1. Extract this ZIP.
2. Upload every extracted file to the root of your GitHub repository.
3. Confirm that `index.html` is visible at the top level.
4. Commit the changes.
5. In Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, and save.

## Open locally
Open `index.html` in a modern browser. The site stores learning progress in browser localStorage.

## Included files
- `index.html`, `style.css`: website structure and styling
- `app.js`, `storage.js`: interactive application and progress storage
- `curriculum.js`, `questions.js`: curriculum and quiz data
- CSV datasets and Markdown reference sheets

The spreadsheet is a limited learning simulator, not a replacement for Microsoft Excel. This is the initial Phase 1 foundation; detailed lessons and additional resources will be added in later phases.
