# Introductory engineering formula reference

## Motion
- Average speed = distance / time
- Average acceleration = change in velocity / time interval

## Force and energy
- Newton's second law: F = m × a
- Work (constant force parallel to motion): W = F × d
- Power: P = W / t

## Electrical calculations
- Ohm's law: V = I × R
- Electrical power: P = V × I
- Series resistance: R_total = R1 + R2 + ...
- Two resistors in parallel: R_total = (R1 × R2) / (R1 + R2)

## Measurement error
- Absolute error = |measured value − reference value|
- Relative error = absolute error / |reference value|
- Percentage error = relative error × 100%

Check units and assumptions before using any equation. These are introductory relationships, not a substitute for engineering standards or safety procedures.
