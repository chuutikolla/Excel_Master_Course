# Microsoft Excel keyboard shortcuts (Windows)

| Shortcut | Action |
|---|---|
| Ctrl + N | New workbook |
| Ctrl + O | Open workbook |
| Ctrl + S | Save workbook |
| Ctrl + Shift + S | Save As (availability may vary) |
| Ctrl + C / Ctrl + X / Ctrl + V | Copy / Cut / Paste |
| Ctrl + Z / Ctrl + Y | Undo / Redo |
| Ctrl + F | Find |
| Ctrl + H | Replace |
| Ctrl + Home | Go to the beginning of the worksheet |
| Ctrl + End | Go to the last used cell |
| F2 | Edit active cell |
| Alt + Enter | New line within a cell |
| Ctrl + 1 | Format Cells dialog |
| Ctrl + ; | Insert current date |
| Ctrl + Shift + : | Insert current time |

Shortcuts can vary by operating system, keyboard layout and Excel version.
